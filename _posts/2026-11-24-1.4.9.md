**1.4.9** introduces full compatibility with **Flutter 3.50.x**, upgrades the Android build toolchain to **Android Gradle Plugin (AGP) 9.3.1** and **Gradle 9.5.0**, adopts **Java 17**, and updates the Houzi REST API plugin to **1.4.9**.

If you're upgrading, follow the [1.4.9 Migration Guide](/tools/upgrading_future_version).

#### Houzi App 1.4.9

- [Improved] Upgraded Flutter SDK support to **Flutter 3.50.x**.
- [Improved] Migrated Android build system to **Android Gradle Plugin (AGP) 9.3.1** and **Gradle 9.5.0**.
- [Improved] Upgraded Kotlin Gradle Plugin to **2.4.20** and Java source/target compatibility to **Java 17**.
- [Improved] Updated Android project configurations for built-in Kotlin and modern AGP DSL compatibility.
- [Fix] Improved social auth token handling for Google, Facebook, and Apple sign-in flows.
- [Fix] Enhanced stability and performance fixes across listing search and navigation.

#### Houzi Rest Api Plugin 1.4.9

- [Improved] Compatibility updates for Houzi App 1.4.9.
- [Fix] General performance optimizations and bug fixes.
