title: version 1.4.9
type: major

**1.4.9** introduces full compatibility with **Flutter 3.50.x**, upgrades the Android build toolchain to **Android Gradle Plugin (AGP) 9.3.1** and **Gradle 9.5.0**, adopts **Java 17**, and updates the Houzi REST API plugin to **1.4.9**.

If you're upgrading, follow the [1.4.9 Migration Guide](/tools/upgrading_future_version).

#### Houzi App 1.4.9

- [New] Added property document attachment support in Add/Edit Property (Add Property V2), allowing multi-file document selection, background upload, deletion, and edit-mode hydration.
- [Improved] Upgraded Flutter SDK support to **Flutter 3.50.x**.
- [Improved] Migrated Android build system to **Android Gradle Plugin (AGP) 9.3.1** and **Gradle 9.5.0**.
- [Improved] Upgraded Kotlin Gradle Plugin to **2.4.20** and Java source/target compatibility to **Java 17**.
- [Fix] Improved social auth token handling for Google, Facebook, and Apple sign-in flows.
- [Fix] Fixed agent and agency ID persistence (`fave_author_agent_id`, `fave_author_agency_id`) during login and default realtor assignment in Add Property, Add Property V2, and Quick Add Property flows.
- [Fix] Fixed property detail page widget lifecycle syncing, static map initialization, stale contact display option updates, and street-only address rendering.
- [Fix] Enhanced stability and performance fixes across listing search and navigation.

#### Houzi Rest Api Plugin 1.4.9

- [New] Added property document attachment upload (`/save-property-attachment`) and delete (`/delete-property-attachment`) API endpoints, and included attachment IDs in property API responses.
- [Fix] Fixed authentication bypass and removed legacy hardcoded secret password checks in social and phone login flows.
- [Improved] Added server-side provider token verification for Google, Facebook, and Apple social logins, plus a **Strict Social Verification** plugin setting to enforce token checks once mobile apps are updated.
- [Improved] Enforced nonce security across endpoints and tightened strict `app-secret` header validation in nonce creation.
- [Improved] Compatibility updates for Houzi App 1.4.9.
