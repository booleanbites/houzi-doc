**1.4.8** is a major release introducing **Houzi AI** — AI-powered features across the app — along with upgraded Android/iOS dependencies and a migration of the iOS project from CocoaPods to Swift Package Manager.

#### Houzi App 1.4.8

- **[Houzi AI]** Three new AI features: **AI Home (Tailored for You)**, **AI Property Search** (natural language + voice), and **Ask About This Listing** (buyer Q&A). See the [AI Features setup guide](/tools/setup_ai_features) to enable and configure them.
- **[BYOK]** Bring your own AI provider key — Google (Gemini), Claude (Anthropic), or OpenAI — configured on the Houzi Rest Api plugin.
- **[Platform Updates]** Upgraded all Android and iOS dependencies; Android AGP 8.13.2.
- **[iOS SPM]** Migrated iOS from CocoaPods to Swift Package Manager (minimum iOS version is now 15).

#### Houzi Rest Api plugin 1.4.8

- New **AI settings tab**: enable AI, add provider API keys, choose models, per-feature toggles, rate limits, output language, and location aliases.

Upgrading from an earlier version? Follow the [1.4.8 Migration Guide](/tools/upgrading_future_version) — the iOS steps are different this time.
