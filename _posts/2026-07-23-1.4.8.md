**1.4.8** is our biggest release yet — it introduces **Houzi AI**, a suite of AI-powered experiences woven across the app, backed by a **bring-your-own-key** model so you stay in full control of the provider, model, and cost. Alongside the AI work, this release upgrades every Android and iOS dependency to its latest version and migrates the iOS project from CocoaPods to Swift Package Manager.

If you're upgrading an existing project, follow the [1.4.8 Migration Guide](/tools/upgrading_future_version) — the iOS steps are different this time — then enable AI with the [AI Features setup guide](/tools/setup_ai_features).

#### Houzi AI — new in 1.4.8

- **[AI Home — Tailored for You]** The home screen now opens with a natural-language search box and a **Tailored for You** section: AI-generated shortcuts built from your own site taxonomies (property types, statuses, features), plus a **Top Matches for You** row. Select and configure it via the [Home AI Layout guide](/houzi-builder/customize_home_ai).
- **[AI Property Search]** Users type — or **speak** — what they want in plain language (*"residential options in Miami, preferably with a swimming pool and outdoor shower"*). Houzi AI parses it into structured filters (type, location, features), returns matching listings, and offers refine-as-you-go follow-up chips like *Under $1M* or *3+ Bedrooms*.
- **[Ask About This Listing]** On the property details screen, buyers can chat with AI about a specific listing. Answers are grounded strictly in that listing's data and come back as rich, actionable cards — map with directions, agent call/message buttons, floor details, and more.
- **[Voice Search]** Natural-language search accepts voice input, powered by on-device speech recognition (adds the microphone permission and speech-recognizer intent on Android).

#### Bring Your Own Key (BYOK)

- **[Your provider, your cost]** Houzi AI runs on **your** AI provider account. Supported providers: **Google (Gemini)**, **Claude (Anthropic)**, and **OpenAI**. Your API key lives on your WordPress server — the app never sees it.
- **[Model choice]** Configure a main **Model** (AI Search, Ask About This Listing) and a cheaper **Lite Model** (home *Tailored for You* suggestions) independently. We recommend the flash / lite / mini tier of each provider — very cost-effective and more than enough for these features.
- **[Spend protection]** Built-in rate limits (per-user-per-hour and per-site-per-day) guard your AI bill out of the box.

#### Houzi Rest Api plugin 1.4.8

- **[New AI settings tab]** A dedicated **AI** tab in the plugin: master **Enable AI** switch, provider selection + API key, main/lite model fields, and per-feature toggles for AI Property Search, Ask About This Listing, and Tailored for You.
- **[Rate limits]** Configurable per-user-per-hour and per-site-per-day caps (defaults 30 / 500).
- **[Output language]** Force generated text to a language code (`en`, `es`, `ar`, …) or use `auto` to follow the app user's language.
- **[Location aliases]** Map the shorthand users type to your real location taxonomies (e.g. `ny, nyc => property_city:new-york-city`), and grow the list from the misses the plugin reports.

#### Platform updates

- **[Dependencies]** Upgraded all Android and iOS dependencies to their latest versions.
- **[Android]** Android Gradle Plugin **8.13.2**; added `RECORD_AUDIO` permission and the `android.speech.RecognitionService` query for voice search; updated the Google Mobile Ads native-ad factories to the new `google_mobile_ads` `NativeAdFactory` API.
- **[iOS → SPM]** Migrated iOS from **CocoaPods to Swift Package Manager** — no more `Podfile`. The provided `ios` folder ships the full SPM setup, the OneSignal Notification Service Extension wired via SPM (`OneSignalExtension`, Do Not Embed), and the mic / speech-recognition usage descriptions. **Minimum iOS version is now 15.**

#### Localization & tooling

- **[New `ai_*` keys]** New AI-screen strings were added to every bundled language (`en, ar, am, es, fa, fr, ku, pt, ro, ru, tr, ur`). Merge these into your app-level `assets/localization/*.json` when upgrading, or the AI screens will show raw keys.
- **[AI Agent Skill]** The built-in [Houzi AI Skill](/ai-agents/houzi_skill) (`.agents/skills/houzi/`) was updated for the new AI features for those who customize the app with AI coding assistants.

Upgrading from an earlier version? Follow the [1.4.8 Migration Guide](/tools/upgrading_future_version) — the iOS steps are different this time.
