**1.4.8** is our biggest release yet. It introduces **Houzi AI**, a suite of AI-powered features across the app, backed by a bring-your-own-key model so you control the provider, model, and cost. It also upgrades every Android and iOS dependency and migrates iOS from CocoaPods to Swift Package Manager.

If you're upgrading, follow the [1.4.8 Migration Guide](/tools/upgrading_future_version), then enable AI with the [AI Features setup guide](/tools/setup_ai_features).

#### Houzi App 1.4.8

- [New] Introduced **Houzi AI**, running on your own API key. Supported providers: Google (Gemini), Claude (Anthropic), and OpenAI. Your key stays on your WordPress server.
- [New] **AI Home**: a redesigned home screen that opens with a natural-language search box and AI-driven sections. Select and configure it via the [Home AI Layout guide](/houzi-builder/customize_home_ai).
- [New] **Tailored for You**: AI-generated search shortcuts built from your own site taxonomies (property types, statuses, features), giving each user quick entry points based on what your site actually offers.
- [New] **Top Matches for You**: a row of listings the AI surfaces as the best fit for the user, shown right on the home screen.
- [New] **AI Property Search**: users type or speak what they want, and Houzi AI turns it into filters, returns matching listings, and suggests follow-up refinements.
- [New] **Ask About This Listing**: buyers chat with AI about a specific listing, with answers grounded in that listing's data and shown as actionable cards.
- [New] **Voice Search**: natural-language search now accepts voice input via on-device speech recognition.
- [Improved] Upgraded all Android and iOS dependencies to their latest versions.
- [Improved] Updated Android to Gradle Plugin 8.13.2, added the voice-search permissions, and moved to the new `google_mobile_ads` NativeAdFactory API.
- [Improved] Migrated iOS from CocoaPods to Swift Package Manager. Minimum iOS version is now 15.
- [Improved] Added new `ai_*` localization strings to every bundled language. Merge them into your app-level `assets/localization/*.json` when upgrading.
- [Improved] Updated the built-in [Houzi AI Skill](/ai-agents/houzi_skill) for the new AI features.

#### Houzi Rest Api Plugin 1.4.8

- [New] Added a dedicated **AI** settings tab: enable AI, choose a provider and API key, set models, and toggle each AI feature.
- [New] Added separate **Model** and **Lite Model** settings so you can use a cheaper model for home suggestions.
- [New] Added configurable rate limits (per user per hour and per site per day) to protect your AI spend.
- [New] Added an output-language setting to force a language code or follow the app user's language.
- [New] Added location aliases to map user shorthand to your real location taxonomies.
